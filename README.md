# 🏃‍♂️💨 《代號：極限追逐》 Tag & Chaos

一款可直接透過瀏覽器遊玩、部署於 **GitHub Pages** 的純靜態 2D Q版幾何派對追逐遊戲。免安裝、免架設伺服器，支援 **單人 vs 電腦 AI** 與 **WebRTC P2P 免伺服器多人連線**！

## ✨ 遊戲特色
- **2D Q 版幾何畫風**：圓角膠囊角色、粗黑邊框、隨移動方向轉動的眼睛、動態腳步與彩虹／烈焰／像素殘影，搭配 6 種頭飾與 8 種角色顏色。
- **5 大職業天賦**：🎒 道具狂、🏃 跑酷專家、🪤 陷阱大師、🌿 夜行者、📣 大嗓門。
- **22 種爆笑隨機道具**：渦輪加速鞋、閃現傳送門、火箭噴射器、空間交換器、彈簧高蹺、香蕉皮、冰凍地雷、黏液沼澤瓶、捕獸夾、彈飛地雷、煙霧彈、閃光震撼彈、混亂毒藥、墨水噴霧、假分身誘餌、偽裝變身卡、泡泡護盾、隱身斗篷、全圖雷達、磁力吸盤、時間減速器、狂暴亂鬥鐘。
- **5 種遊戲模式**：經典追逐、感染模式、燙手山芋、救援牢籠、鑰匙逃脫。
- **3 張主題地圖 ＋ 簡易地圖編輯器**：辦公室／校園迷宮、極限滑冰場、輸送帶工廠，支援隱藏草叢、電動閘門開關、單向加速帶、雙向傳送陣、可破壞木箱、積水腳印與 JSON 地圖代碼匯出／匯入。
- **派對張力機制**：全場突發事件（大停電、強風、2 倍速、天降道具雨）、最後 30 秒毒圈縮小、最後 20 秒狂暴時刻、視野迷霧、心跳警報與觀戰者場外空投搞事技能！
- **Web Audio 8-bit 即時合成音效**：零外部音檔依賴，開網頁即可遊玩。

## 🎮 操作說明
- **移動**：`WASD` 或 `方向鍵`（手機／觸控裝置提供左下角虛擬搖桿）
- **使用道具**：`空白鍵 (Space)` 或 `滑鼠左鍵`（道具狂按 `Q` 切換雙道具）
- **專屬動作（冷卻 5 秒）**：`Shift`（逃跑者：翻滾衝刺；追逐者：猛撲抓捕）
- **快捷表情**：`1` 😂、`2` 😱、`3` 👍、`4` 😡

## 🌐 部署至 GitHub Pages
本專案為純靜態 HTML5 + ES Modules 網頁（透過 CDN 載入 PeerJS 進行 WebRTC P2P 連線），可直接於 GitHub Repository 設定 **Settings → Pages → Deploy from a branch (`main` / `/ (root)`)** 上線遊玩！
